# Orixios — أساس شات المدرّس الذكي (Core Tutor Chat)

المرحلة الحالية تنفّذ فقط أساس شات المدرّس: واجهة شات، واجهة برمجة، طبقة مزودين،
مفاتيح مستخدم (Mock)، جلسات مواد، مصادر موثوقة تجريبية، ومهارات المدرّس.
لا تُخزَّن الرسائل في قاعدة بيانات بعد، ومفاتيح المستخدم في `localStorage` مؤقتًا.

## التشغيل

نستخدم **npm** كمدير حزم وحيد في المشروع.

```bash
npm install        # تثبيت الاعتماديات
npm run dev        # التشغيل للتطوير
npm run build      # البناء الإنتاجي
npm run lint       # فحص ESLint
npx vitest run     # تشغيل الاختبارات
```

متغير البيئة الوحيد الخاص بهذه المرحلة:

```
DEV_TESTING_MODE=false
```

- عندما يكون `false` لا يستخدم النظام أي مفتاح بيئي تلقائيًا إطلاقًا.
- عندما يكون `true` يمكن تمرير مفتاح تطوير مخصص عبر `DEV_TESTING_API_KEY` فقط
  (لا يُقرأ `GEMINI_API_KEY` ولا أي مفتاح بيئي آخر في أي مكان من المشروع).

| الطبقة | المكان |
| --- | --- |
| واجهة الشات | `src/components/tutor/` |

| مزودو الذكاء الاصطناعي | `src/lib/ai-providers/` |

### قرارات معمارية موجزة

- **اختيار المزود خارج React**: منطق ترتيب المفاتيح وإعادة المحاولة وحدات نقية
  في `lib/ai-providers` تُستخدم من الخادم وقابلة للاختبار مباشرة.
- **قواعد المفاتيح**: استنفاد الحصة يعلّم المفتاح `exhausted` ويجرّب المفتاح
  التالي؛ المفتاح غير الصالح يُعلَّم `invalid` ويتوقف فورًا دون انتقال تلقائي؛
  فشل الجميع يعيد `ALL_KEYS_EXHAUSTED`.
- **قفل المادة**: الجلسة تُحسم في الخادم (`session-store`)، وأي طلب بنفس
  `sessionId` بمادة مختلفة يعود بخطأ `SUBJECT_LOCKED` (409).
- **التأهيل لـ Supabase**: `SessionStore` وواجهة تخزين المفاتيح وتحميل المصادر
  نقاط استبدال معزولة بتواقيع ثابتة.
- **مزود المحاكاة التطويري (`mock`)**: يسمح بتجربة الشات كاملًا دون أي مفتاح
  خارجي؛ يقرأ المصادر المضمنة في الـ prompt ويرد وفق شخصية المدرّس،
  ويصرّح بوضوح أنه محاكاة.

## قيود مؤقتة في هذه المرحلة

- المفاتيح في `localStorage` (تطوير فقط)؛ تُستبدل لاحقًا بتخزين مشفر عبر Supabase.
- الرسائل غير مخزنة؛ تُرسل في كل طلب من الواجهة.
- الآلة الحاسبة (mathjs) مثبتة كاعتمادية لكن واجهتها غير منفذة بعد.
- اختيار المادة من النص المكتوب مطابقة تامة فقط؛ نقطة تطوير جاهزة
  في `lib/sessions/subject-matcher.ts`.
- الاستجابة غير تدفقية (رد كامل واحد) لتبسيط الأساس.
